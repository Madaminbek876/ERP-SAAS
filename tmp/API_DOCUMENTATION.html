Versiya: v1 Base URL: http://<server>/api/v1/ Swagger UI: http://<server>/swagger/ ReDoc: http://<server>/redoc/

UMUMIY QOIDALAR

Autentifikatsiya

Barcha endpointlar (login va token/refresh bundan mustasno) Authorization headeri talab qiladi:

Authorization: Bearer <access_token>

Pagination (sahifalash)

Ro'yxat (list) endpointlari sahifalangan javob qaytaradi:

{
  "count": 150,
  "next": "http://<server>/api/v1/orders/?page=2",
  "previous": null,
  "results": [ ... ]
}
Parametr Turi Tavsif
page integer Sahifa raqami (default: 1)
page_size integer Har sahifadagi yozuvlar (default: 20)

Misol: GET /api/v1/orders/?page=2&page_size=10

Qidiruv va Tartib

?search=qidiruv_matni       # matnli qidiruv
?ordering=field_name        # o'suvchi tartib
?ordering=-field_name       # kamayuvchi tartib

Xatolik formatlari

{ "detail": "Not found." }
{ "field_name": ["Xatolik matni."] }
{ "non_field_errors": ["Xatolik matni."] }

HTTP Status kodlari

Kod Tavsif
200 Muvaffaqiyatli (GET/PATCH)
201 Yaratildi (POST)
204 O'chirildi (DELETE)
400 Validatsiya xatosi
401 Autentifikatsiya xatosi
403 Ruxsat yo'q
404 Topilmadi
409 Konflikt (bog'liq yozuvlar bor)

Enum qiymatlar (barcha bo'limda ishlatiladi)

CurrencyCode: UZS

PaymentMethod: CASH | BANK_TRANSFER | CARD

PaymentStatus: UNPAID | PARTIAL | PAID

ItemType: RAW_MATERIAL | FINISHED_PRODUCT

StockMovementType: IN | OUT | WASTE | ADJUST | RETURN

KontragentKind: SUPPLIER | CLIENT | BOTH

1. ACCOUNTS (Autentifikatsiya)

Base: /api/v1/accounts/

1.1 Login

POST /api/v1/accounts/login/

Auth: Shart emas Throttle: 10 ta so'rov/minut

Request body:

{
  "username": "admin",
  "password": "secret123"
}

Response 200:

{
  "access":  "eyJhbGci....",
  "refresh": "eyJhbGci...."
}

access tokeni 60 daqiqa, refresh tokeni 7 kun amal qiladi.

1.2 Token yangilash

POST /api/v1/accounts/token/refresh/

Auth: Shart emas Throttle: 20 ta so'rov/minut

Request body:

{
  "refresh": "eyJhbGci...."
}

Response 200:

{
  "access":  "eyJhbGci....",
  "refresh": "eyJhbGci...."
}

ROTATE_REFRESH_TOKENS=True — har safar yangi refresh token beriladi, eski blacklist bo'ladi.

1.3 Profil ko'rish

GET /api/v1/accounts/me/

Auth: Majburiy

Response 200:

Frontend uchun yuklab olish misoli (JavaScript):

async function downloadShipments(filters) {
  const params = new URLSearchParams()
  Object.entries(filters).forEach(([k, v]) => { if (v) params.set(k, v) })

  const res = await fetch(`/api/v1/orders/shipments/export/?${params}`, {
    headers: { 'Authorization': `Bearer ${accessToken}` }
  })
  const blob = await res.blob()
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = 'shipments.xlsx'
  a.click()
  URL.revokeObjectURL(url)
}
